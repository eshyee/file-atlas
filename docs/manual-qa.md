# 本地功能验收

媒体预览只读取来源文件；验收时使用独立的临时应用数据目录，不执行整理。真实照片、索引数据库、临时转换结果和带路径的报告均留在本机，不放入仓库或公开截图。

## 媒体预览入口

- 在归并清单和重复文件清单中，JPEG、ARW 等 RAW、MP4、AVI 等后端支持的图片及视频格式均应显示预览按钮；SVG、脚本、文档和音频文件不显示此按钮。
- `.ts` 同时可能是 TypeScript 代码或 MPEG-TS 视频，仅在分类扫描确认其为视频时提供预览按钮，归并和重复清单不凭该后缀推断。
- RAW 预览优先使用原文件内嵌 JPEG；不支持的文件应显示格式解码提示，原文件保持不变。
- 用浏览器检查转换视频确有画面、可播放且非零时长；HTTP 成功或存在 MP4 文件本身不能证明转换成功。
- 桌面和 390 px 窄屏分别检查预览弹窗、关闭按钮、视频控制条和错误信息，页面不得横向溢出。

## 离线人脸索引

- 将本地 YuNet/SFace ONNX 模型放在含中文的文件夹内，构建索引；模型通过 Python 读取并校验内容，再以内存缓冲区交给 OpenCV，不依赖 Windows 路径编码。
- `python -m pytest tests/test_faces_models.py -q` 使用 `build/face-models` 的本地模型验证中文路径下的真实加载及两个网络推理；也可设置 `FILEATLAS_TEST_MODEL_DIR`。缺少可选依赖或模型时跳过，不下载模型。
- 当前人脸索引支持可解码照片；RAW 会明确报告暂不解码，可索引同目录的 JPEG。格式限制不应当显示为权限不足。
- 验收前后比较来源文件的 SHA256、大小和时间戳；不要将真实照片或人脸特征作为自动化测试资料提交。
